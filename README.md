# Carousel Channel Drift

Trazer o projeto de sales.lle.sh para cá:
- Manter a estrutura exata da moldura/aplicação de televisão sem alterar a estrutura base.
- Tirar aquele monte de coisas e tabelas de vendas que estavam dentro do painel principal e deixar limpo com a logo ll e.s h / n o ii perfeitamente centralizada e com o tamanho bem ajustado.
- No topo, ao clicar no seletor para mudar de canal, fazer um seletor tipo mala (que gira/passa para cima e para baixo estilo rolete de cadeado de mala/drum picker, e não uma lista simples suspensa) para alternar suavemente entre os canais e frentes de trabalho.
- No celular/telefone, deixar responsivo e funcionando bem para trocar de canal pelo seletor.
